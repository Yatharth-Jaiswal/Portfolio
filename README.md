# Dark Developer Portfolio // Yatharth Jaiswal

A high-performance, dark-themed technical portfolio built with **React**, **Vite**, **Lenis Smooth Scroll**, and **GSAP ScrollTrigger**.

## 🚀 Developer Profile
- **Developer:** Yatharth Jaiswal
- **Role:** Web Developer
- **Tagline:** I build interactive, responsive and performance-focused digital experiences.
- **Location:** India // Open for Remote & Worldwide Opportunities

## 🛠️ Tech Stack
- **Framework:** React / Vite
- **Styling:** Modular Vanilla CSS with Custom Design Tokens
- **Smooth Scroll & Physics:** Lenis Smooth Scroll + GSAP ScrollTrigger
- **Icons:** Lucide React

## 📦 Getting Started

```bash
# Clone the repository
git clone https://github.com/Yatharth-Jaiswal/Portfolio.git

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
